# /player/ and /watchlist/ are deliberately NOT disallowed here. Both already
# serve <meta name="robots" content="noindex, follow">, and that is the
# directive that actually removes them from an index. Blocking them here would
# stop crawlers fetching the page at all, so they would never read the noindex —
# the pages would sit in Search Console as "Indexed, though blocked by
# robots.txt", which is the opposite of what blocking them is meant to achieve.
# `follow` also keeps link equity flowing on through to the catalogue.
#
# /api/ is different and stays blocked: those endpoints return JSON, so there is
# no HTML head to carry a noindex in.
